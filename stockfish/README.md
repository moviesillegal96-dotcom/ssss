# Stockfish 19 (Lite, single-threaded WebAssembly)

Copied unmodified from the `stockfish` npm package v19.0.0 (https://github.com/nmrugg/stockfish.js),
a WebAssembly build of Stockfish (https://stockfishchess.org).

Stockfish is free software licensed under the GNU General Public License v3; see `COPYING.txt`.
Source code: https://github.com/official-stockfish/Stockfish and https://github.com/nmrugg/stockfish.js

`chess-helper.html` uses these files when it is served over http(s) (the Android app does this);
opened as a plain local file it falls back to its built-in engine.
